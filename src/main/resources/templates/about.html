About this system and its data

Where the records come from

Records may only come from sources this project is permitted to use: an approved airline or airport API or partner integration, a permitted data export, or details an administrator enters manually from information they have permission to use. Airport and airline web pages are never scraped, access controls are never bypassed, and passenger information is never republished without authorization.

Each record shows its source, the date it was last checked against that source, and whether an administrator has verified individual details. When a source did not confirm something, the page says Not specified; the system does not guess status, location, flight details or ownership.

Current state of this installation

  • Live synchronization with an airport or airline system: not implemented.
  • Authorized API connection: none configured (see the README for why public access is not available).
  • The data shown is demonstration data only. It is not real baggage.
  • The database holds authorized records and some demonstration records; demonstration records are labelled.
  • The database holds records entered or imported by administrators from permitted sources.
  • The database is empty.

Need current information about a bag?

Contact the baggage service desk of the airline you flew with, or the lost-and-found / baggage services office of the airport, and quote your tag ID or case reference. They hold the authoritative, up-to-date record.
